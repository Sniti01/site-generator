== 2. push X → прогон X; через минуту push Y (revert X) → прогон Y ждёт в очереди
  шаг 3 прогона X (голова = X): ok=true: коммит запуска 1111111111111111111111111111111111111111 = голова main — выкладывается он
  перед mirror прогона X голова уже Y — сверки нет; будь она, сторож сказал бы: ok=false: СТОП: коммит запуска 1111111111111111111111111111111111111111 — не голова main (2222222222222222222222222222222222222222): это повтор старого запуска …
  фактически: mirror выкладывает X (не голову main, без входа отката); прогон Y стартует только после конца прогона X
  (очередь concurrency) и доходит до своего mirror ещё через ~3 минуты — всё это время живой сайт — отменённый X.
