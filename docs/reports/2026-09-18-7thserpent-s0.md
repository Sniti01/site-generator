# 2. Ядро (`120b6ae`) — читалка и судья контраста

**`core/structure/clustering.mjs` — два формата, один выход.** `google` —
четыре листа, объём «Google, ср/мес», сводная с листа «Кластеры»;
`volume` — один лист «Clustering», объём «Частотность», сводная —
группировкой строк: число фраз счётом, объём суммой, топ-фраза — максимум
(при равенстве — по алфавиту), ранг — с дележом равных, как на листе
первого формата. Формат — по наличию листа «Кластеры»; `meta.format`,
`meta.volumeColumn`. Поле объёма зовётся `google` в обоих (контракт,
бэклог 52 п. 1). Сводные колонки формата `volume` («Фраз в группе»,
«Частотность группы») требуются, но не читаются: у «Некластеризовано»
первая даёт 1 при 59 строках (проверено: суммы сходятся у 103/103 групп,
число — у 102/103).

**Сторожа обоим форматам** (по рецензии, F2–F8): пустой запрос, пустая
группа, повтор запроса, повтор заголовка колонки — отказ с номером строки
листа по атрибуту `r`; пустая строка листа пропускается. **Разбор XML:**
самозакрытые `<c …/>` и `<row …/>` (так Excel пишет пустые стилевые
ячейки при пересохранении) читаются как пустые, а не глотают соседа
(F1 — до правки `<c r="B2" s="1"/>` принимался за открывающий тег,
и «Частотность группы» становилась объёмом фразы — молча); `<t/>`
не глотает разметку составного текста; «1,300» — тысяча, не 1.3.

**Самопроверка `--selftest`** — мини-xlsx в памяти (zip + XML своим
кодом): формат `volume` в диалекте Excel (самозакрытые ячейки и строки,
формула с кэшем `t="str"`, составной текст с пустым прогоном), формат
`google` через `sharedStrings.xml`, семь отказов. 23 пробы; шесть
нарочных мутаций пойманы (раздел 1).

**`core/gates/check-contrast.mjs`** — комментарии снимаются до поиска
блоков и сбора токенов **сканером со знанием строк** (первая редакция
среза регулярным выражением дала бы тихий проход с нулём пар при
`@source '../src/*.astro'` — находка A1 рецензии); блоки `@theme … {`
(и `@theme inline {`) и голый `:root {` ищутся по началу строки; BOM

# 8. Факты, важные будущим сессиям

1. **`main` не перемотан до `23b6338`** — сессия 5 стартует от головы
   этой ветки или от `main` после перемотки владельцем; ветки — линейная
   цепочка, слияний нет.
2. **Читалка отвергает дубли запросов и пустые строки с данными** — экспорт
   с такими строками теперь падает на гейте структуры с адресом строки,
   а не проходит с тихой порчей учёта.
3. **`format: volume` — по отсутствию листа «Кластеры»,** не по имени
   файла; одно-листовой экспорт с объёмом WS читался бы так же (бэклог 53
   п. 1 — источник объёма нужно объявлять данными сайта).
4. **Судья контраста требует оба блока голым `@theme {` / `:root {`
   по началу строки** и снимает комментарии со знанием строк; ноль пар
   больше не проходит.
5. **`s0-recon.json` первого сайта при следующем `npm run recon` получит
   две новые строки `meta`** — не регрессия (бэклог 53 п. 7).
6. **Корпус второго сайта тонкий:** живого HTML ≈ 470 документов из 612
   `ok` (YouTube и rockstargames — оболочки); reddit/fandom/gamefaqs
   закрыты. Анатомия S3 хабов сойдётся на steamcommunity (42), ign (30),
   wikipedia (13), gamepressure (7); корзины high всего 16.
7. **Правила S0 второго сайта — все словари данными:** новая тема, хаб
   или слово магазина — правка `rules-s0.json`, не кода; порядок
   признаков — тоже данными.
8. **Правка CRLF-файла без смены окончаний** — скрипт точной замены
   (`edit-exact.mjs` в scratchpad этой сессии): каждое `old` ровно один
   раз, LF в спецификации → окончания файла; после правки — проверка
   на одинокий LF. Инструмент Edit нормализовал бы окончания.
9. **Состязательные рецензии судей** — два агента с разными линзами
   и предписанием опровергать собственные находки; выход: подтверждённые
   с воспроизведением, опровергнутые — строкой. Стоило одного тихого
   прохода (A1) и одной тихой порчи (F1), которых ни самопроверка,
   ни живые файлы не показали бы.
