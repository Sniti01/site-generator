Два скептика: «опасный проход» (`opasno/`, находки SV1-O) и «законные формы и ложный отказ» (`zakon/`, SV1-Z). Каждая
находка воспроизведена своим скриптом на образцах, без сети и без сервера FTP; что без lftp и GitHub не воспроизводится —
помечено скептиком «не воспроизведено: довод». Правка — после падающих проб: `krasnyi.txt` — прогон новых проб на прежней
редакции (77 проб, красных 40), затем новая редакция сторожа и workflow — 77 из 77. Модель сборки CI скептика «законных
форм» (`zakon/sim-ci.mjs`, `sim-ci-imena.mjs`: настоящий компилятор Astro с путём раннера) в репозиторий не положена —
производное, 8 МБ; воспроизводится скриптами.

Держит (скептики): `indeks` — ровно один canonical, равный главной; `sekrety` значений не печатает; стоп домена при сбоях
сети; `bash -e` и `cmd:fail-exit` — упавшая команда lftp останавливает шаг; `.git` корпуса внутри `raw/` безвреден
(указатель читает файлы по манифесту); окончания строк сборки; `inputs` при push.

Риски, которые без Linux и сети не проверить (скептик «законных форм», Р-1…Р-4): гейт знака в `npm run build` на Linux
перерисовывает PNG иконок через sharp и сверяет байты с `public/`, нарисованным на Windows, — сборка второго сайта на
Linux не шла ни разу; байты webp и версия Node (локально 26.4, CI — 24); файлы хостера, которые робот не может удалить.
Первый запуск workflow покажет; в докладе — вопросом.
