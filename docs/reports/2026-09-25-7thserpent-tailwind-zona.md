# 2. Правка (п. 1)

```css
@import 'tailwindcss' source('../../src');
/* … (прежний комментарий о сужении ядра) … */
@source '../../../../core/**/*.astro';
/* Файлы содержания `src/content/` — не источник кандидатов (П86 п. 2, П87):
   Tailwind читает их как любые другие, и слово текста становится утилитой

   Остальная зона не сужается: `src/` сайта — с текстами главной в `src/data/` —

@source not '../content';
```

Путь — от файла листа (`src/styles/` → `src/content/`), как требует документация Tailwind
для `@source not`. `source('../../src')` и `@source` ядра не тронуты. Первая редакция
комментария начиналась словами «Тексты страниц — не источник кандидатов» — шире сделанного:

# 8. Факты, важные будущим сессиям

- **`@source not '<путь>'`** — путь от файла листа; `'../content'` исключает всё под
  `src/content/`, включая вложенные папки; `content.config.ts` и `src/data/` остаются в зоне.
- **Tailwind читает и сам `global.css`**, но из `.css` берёт только имена CSS-переменных:
  слова комментариев листа кандидатами не становятся. Комментарий YAML в `.md` — становится
  (маркер `z-[73]` это показал).
- **Сборка без правки и с правкой воспроизводит имена листов** (`LinkList.DV_wl0J6.css`,
  `LinkList.Bl5rmwFn.css` в обоих проходах маркеров): кэша Tailwind между процессами нет.
- **13 из 14 утилит слоя — ложные кандидаты из кода**, настоящая одна — `.container`
  (бэклог 62 п. 2).
- **`astro preview` Astro 7 живёт в фоне между сессиями** (`astro preview status`, `stop`);
  перед съёмкой — сверка отдаваемого с `dist/`.
- **Playwright MCP:** в контексте `browser_run_code_unsafe` нет глобального `URL`.
- **Воркфлоу:** имена полей схемы — только латиница.
