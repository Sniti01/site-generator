# 8. Факты, важные будущим сессиям

1. **Гарнитура шасси обязана нести `tnum`:** на табличных цифрах стоят
   `.tabular` ядра (даты `CardRail`, время `LinkList`, номера `Toc`, счётчик
   `LinkColumns`, год `ChipNav`); проверять `fontTools` по файлу и замером
   «1111» = «0000».
2. **Chromium при заданном `scrollbar-color`/`scrollbar-width` правила
   `::-webkit-scrollbar` не применяет** — у шасси обоих сайтов часть правил
   полосы прокрутки мёртвая.
3. **Гейт контраста считает только пары токенов:** текст поверх скрима
   и арта, `color-mix`, полупрозрачная шапка — вне гейта; страницы с артом —
   замером пикселей.
4. **Признак оглавления второго сайта:** узел с классом — при двух разных
   разделах страницы внутри; Steam — по первой строке `onclick`. Любая правка
   словаря или признака → `npm run anatomy`, затем `npm run tree`; слепок
