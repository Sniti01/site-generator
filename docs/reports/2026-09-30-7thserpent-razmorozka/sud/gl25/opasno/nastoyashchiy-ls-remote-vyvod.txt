   f22bb920398794800ae78474dbe5d5a839ce6c76	refs/heads/main

Следствие (по коду builtin/ls-remote.c: образец «*/<образец>» против «/<имя ссылки>»): ветка или метка с именем,
оканчивающимся на «/refs/heads/main» (например refs/heads/x/refs/heads/main), дала бы вторую строку — сторож: СТОП
«голову main не узнать» (ложный стоп, не проход). Проверка на синтетике:
   golova(две строки) → ok=false: СТОП: голову main не узнать — git ls-remote дал не одну строку «<коммит> refs/heads/main»; сервер не тронут. Новый запуск кнопкой Run workflow; повторяется — проверь, что репозиторий открыт для чтения, и пришли строку СТОП.
