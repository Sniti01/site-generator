# 3. Предусловие 2 — бэклог 44: схема содержания не строгая (и 28 — та же схема)

**Факт:** `content.config.ts` — `z.object()` без `.strict()`, неизвестные
поля файла содержания Astro молча срезает (`title`, `description` пройдут
вопреки П24 п. 3); поле блока, которого нет в `blocks[]` страницы, маршрут
молча игнорирует (`cta` у карты, `verdict` у Rodowód — доклад пачки 4).
Смежный **28**: `lead`, `primary`, `secondary` обязательны у страницы без
героя — семь страниц носят их «ради схемы».

**План одной правкой контракта содержания (владелец):**

1. `.strict()` на объекте схемы и на вложенных объектах — неизвестный ключ
   роняет сборку с именем файла и ключа.
2. Сверка «поле без блока» в `maTresc` маршрута: поле блока, не объявленного
   в `blocks[]` страницы, — отказ с именем (сегодня отказ только в обратную
   сторону — блок без поля).
3. Поля героя — необязательные; требование — предикатом
   `maTresc['hero-key-art']` (страница с героем без лида падает, без героя —
   нет); семь файлов без героя чистятся от полей «ради схемы».
4. Файлы содержания приводятся к контракту: лишние поля (`cta` у карты,
   `verdict` у Rodowód и что найдёт `.strict()`) снимаются — **пиксель не
   меняется**: эти поля и так не печатались; `check` после — обязателен.
5. Отрицательные пробы — три: неизвестный ключ, поле без блока, герой без
   лида; положительная — 30 файлов проходят, 31 страница строится.

Варианты для владельца: **(а)** пункты 1–5 целиком (44 + 28 одной правкой);
**(б)** только `.strict()` (44) — 28 позже. **Рекомендация — (а)**: один
файл, одна сессия, одна батарея проб; второй сайт получает строгий контракт
до первого текста. Цена — одна сессия; пересъёмки не нужно.
