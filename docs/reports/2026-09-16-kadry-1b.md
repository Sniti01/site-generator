# 3. Ezio — герой, лид, коридор

**Герой из Revelations, не из Brotherhood — решение исполнителя с причиной.**
План (раздел 5) писал «Brotherhood `-k<nn>` мастером 1920 с Эцио в Риме».
Измерено по листу и полным кадрам: Brotherhood отдаёт **1280×720**, кадры
[0–7] — мультиплеер без Эцио, [8–12] ставят Эцио на 8–26 %, 12–47 %,
34–58 %, 78–93 % и 52–60 % ширины. Геометрия героя (`HeroKeyArt.astro`),
всё в координатах кадра 16:9: арт занимает правые 68 % ширины героя при
высоте `clamp(600px, 90vh, 920px)`; на 1440×900 это 979×809, `object-fit:
cover` показывает полосу 16–84 % ширины кадра (x героя = x кадра + 16 %);
скрим героя даёт альфу 0,74 на 52 % героя (= 36 % кадра) и 0,12 на 78 %
героя (= 62 % кадра) — сюжет должен стоять в 58–84 % кадра (альфа ≤ 0,22). Из всех кадров Brotherhood и Revelations этому отвечает только
**Revelations [3]** (Эцио 60–83 %, центр ≈ 73 %; три линзы измерили 72/73/74).
Цена: мастер 1280 → на 1440 растяжение 1,125×, на 1920 — 1,28×, `srcset`
только 1200 и 1280 (`widths` 1600+ не порождаются) — на экранах Retina
герой мягче keyart-героев 3840 (их пять: `hero`, Mirage, Origins, Unity,
Valhalla); тот же класс, что у героев `/assassins-creed-2/`
и `/assassins-creed-revelations/` (1280×720) и `/assassins-creed-1/`
(1077×605), судья Black Flag — 1920; на 390 сюжет у правого края с подрезом,
**как у героя Black Flag** (`karaiby [0]`, тот же центр-кроп 16:9 —
сравнение `black-flag-hero-390.jpg` / `ezio-hero-390.jpg`). Отмена —
за владельцем: запасной путь — Brotherhood [12] героем (Эцио наполовину
под скримом) и Brotherhood [9] ряду `rzym`; путь через `object-position`

# Факты, важные будущим сессиям

1. **Витрина Steam отдаёт старые игры мелко:** AC2 и Brotherhood — 1280,
   AC1 — до 1680, Revelations — 1280 кроме [2]; «мастер 1920» — только
   у игр с 2013 года. Герой из скриншота такой игры растягивается —
   считать до выбора.
2. **Brotherhood [0–7] — мультиплеер** (персонажи «Doctor», «Priest»,
   «Nobleman», «Prowler», «Courtesan», «Executioner»), Эцио нет; проверка
   кадра «по одному» это не распознала — сюжет кадров Brotherhood/Revelations
   сверять глазами, не описанием.
3. **Геометрия героя (в координатах кадра 16:9):** на 1440×900 видна
   полоса 16–84 % ширины кадра, x героя = x кадра + 16 %; скрим 0,74
   на 36 % кадра, 0,12 на 62 % — сюжет героя ставить в 58–84 % кадра;
   на 390 — центр-кроп 17–83 % без бокового скрима.
4. **Рамка ряда 21:13 у́же 16:9** — кадр теряет ≈ 4,5 % ширины с краёв,
   не высоту; высоту теряют кадры ниже 1,615 (4:3-подобные).
5. **`fullPage` Playwright ловит `sticky`-шапку посреди кадра** (она
   рисуется в позиции прокрутки на момент захвата); для кадров «для глаз» —
   `header.hdr { position: static !important }` на время снимка (место
   в потоке то же); `loading="lazy"` — прокрутить шагами 0,8 экрана
   с паузой 250 мс и дождаться `img.complete`, иначе ряды пустые. Вьюпорт
   высотой во всю страницу не годится: `40vh`/`90vh` героя растягиваются.
6. **`img.naturalWidth` в Playwright у `webp` из `srcset` может показать
   размер больше файла** (2448×1376 у 1280×720) — размер мерить `sharp`,
   не DOM.
7. **Знаки героя = лид + две подписи** (кнопки), `<h1>` тот же, что
   в `.page-head`; 202 + 26 = 228 сошлось с гейтом до знака.
8. **`git add --renormalize --dry-run .` перечисляет все отслеживаемые
   файлы** (619 на старте, 629 после десяти `jpg`) — это не список
   изменяемых; проверка окончаний — `git ls-files --eol` по правленным.
