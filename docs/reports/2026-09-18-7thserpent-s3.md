# 7. Факты, важные будущим сессиям

1. **Детекторы элементов по классам ненадёжны без выреза кода и учёта
   скрытости:** на этом корпусе класс галереи чаще стоит у заготовок
   каруселей и скрытых окон, чем у галерей. Любой новый признак — только
   с документом фикстуры, где он единственный решает исход.
2. **`s3-anatomy.json` несёт отпечаток правил (`rules-s3.json` +
   `rules-s0.json`) и набора фраз каждой страницы;** `build-tree`
   останавливается, если они не совпадают с живыми файлами и раскладкой.
   Правка правил или объявления → `npm run anatomy`, затем `npm run tree`.
3. **Коридор существующей строки `structure.json` переживает перемер**
   (именованное решение П43) — `tree:check` его не ловит, только строка
   «коридор из контракта». До приёмки строки сессии снимались перед
   `npm run tree`; после приёмки — только именованным решением.
4. **Слепок правил в пробах** (`правила: слепок структуры`) падает на любой
   правке словарей и признаков — его обновляют вместе с перемером
   и строкой в докладе.
5. **Стенка возраста Steam стоит в выдаче и своим адресом** — у каждой
   стенки проверяется итоговый адрес, а не только переход.
6. **Числа в документах — только из выхода инструмента;** числа проверки
   помечаются «по рецензии» или «по разбору» с редакцией.
7. **Сторож дерева на вердикт** сверяет его с долей, минимумом документов
   и корзиной: рукой правленный `s3-anatomy.json` в контракт не проходит.
