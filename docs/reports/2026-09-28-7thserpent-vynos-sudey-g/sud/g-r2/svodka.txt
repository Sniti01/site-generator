---- GR2-K-2 дефект → подтверждено
ОПИСАНИЕ: Класс «@property --font-display меняет гарнитуру на странице» (R4-SVERKA-2, проба R5-SVERKA-4) закрыт только для global.css, где iskat ищет его на любой глубине. На пути оракула @property отдельно не судится вообще. Верхнеуровневое `@property --font-display` в импортированном листе ловится лишь случайно: Tailwind выводит для него запасное `--font-display: initial` (или initial-value), и это значение не проходит проверку списка. Если же `@property --font-display { syntax: '*'; inherits: false; }` вложено в @layer, @supports или @media импортированного листа (ядро), Tailwind запасного значения не выводит, судья говорит «сверено», а правило доходит до страницы. При сжатии (minify, как у плагина в сборке) `@media all` раскрывается, и @property оказывается на верхнем уровне. При inherits:false `var(--font-display)` у `.t-headline` получает начальное значение, то есть гарантированно недействительное. font-family становится недействительным, и заголовок падает на наследуемую гарнитуру (Public Sans). Ни в шапке, ни в строке 13 реестра этот предел не назван.
ПРАВКА: В обходе вывода пути сборки (рядом с obojti для @font-face) на любой глубине отвергать `@property`, у которого имя после razekranirovat равно --font-display. Строку отказа дать своего вида, а не опираться на запасное значение Tailwind.
ТЕСТ: Проба: `@property --font-display { syntax: '*'; inherits: false; }` в импортированном листе внутри @layer base, @supports (display: grid) и @media all → ждём отказ «зарегистрирован @property». Контроль — тот же @property в global.css (уже есть в R5-SVERKA-4).
ПРОВЕРЯЮЩИЙ: Воспроизведено скриптом k234.mjs (k234.txt). `@property --font-display { syntax:'*'; inherits:false; }` в импортированном листе внутри `@layer base`, `@supports (display: grid)` и `@media all` даёт СВЕРЕНО. В выводе Tailwind есть `@property --font-display`, а запасного `--font-display: initial` нет: на странице только значение Bodoni Moda. При minify:true (так плагин работает в сборке) `@media all` раскрывается, и @property стоит на верхнем уровне сразу за `.skip-link:focus-visible{…}`, без обёртки. Это действие в браузере без оговорок: при inherits:false у `.t-headline` var() недействителен, и гарнитура падает на наследуемую. Контроль — верхний уровень импорта: ОТКАЗ приходит только строкой «Tailwind сайта не выводит … (выводит: initial | …)», то есть через запасное значение, а не строкой «зарегистрирован @property». ---- GR2-K-3 дефект → подтверждено
ОПИСАНИЕ: Класс «своя @font-face 'Bodoni Moda' подменяет файл темы» (R5-SVERKA-3, -7; GR1-K-4) на странице закрыт только проверкой имени файла по окончанию.
