## 9. Факты, важные будущим сессиям

1. **`naturalWidth` при `srcset` с дескрипторами `w`** — это ширина, пересчитанная по `sizes`, а не
   ширина кандидата. Ширину кандидата берут из дескриптора `currentSrc`.
2. **`grep -c $'\r'` в Git Bash врёт** — насчитал CR в файлах, где их 0. Окончания строк считать байтами
   через node.
3. **Пробы с подменой файлов (`proby-tresci`, `proby-p1`, `proby-p2`)** требуют, чтобы подменяемые
   файлы совпадали с индексом git. Поэтому порядок такой: коммит, сборка, пробы. Пока идут пробы,
   агенты не читают репозиторий.
4. **Общий Chromium Playwright MCP.** Агентам — только свои контексты (`newContext`) и свои порты.
   Под нагрузкой от параллельных агентов растеризация картинок главной расходится до 4 уровней
   (p2-f2), поэтому прогоны против эталона снимать без нагрузки.
5. **Кеш записей Astro:** проверка схемы «не позже дня сборки» идёт при разборе файла, а не при каждой
   сборке. «День сборки» — по поясу машины.
6. **Сторож 8 слов — без морфологии.** Одно окончание (`reflection` → `reflections`) пропустило
   11-словный пересказ Википедии. Пачкам — разовая проверка со срезом окончаний
   (`zamery/ngram-srez-okonchaniy.mjs`).
7. **Корпус:**
   - в сыром корпусе есть американская витрина PS Store с версией PS4 первой игры (товар и концепт),
     плюс индийская;
   - у GOG — только страницы Dreamlist «Vote to bring this game to GOG» и, у первой игры, прежний wishlist;
   - `alt` у `mp1-k14` ссылается на соседний кадр («on the same snowy street»).
8. **Запас коридоров.** `/remake/` — 3954 при нижней границе 3753, `/max-payne-1/` — 2546 при верхней 2797.
9. **Заместители на пачки 3–5 и публикацию** — прогноз раунда 1 в бэклоге 64 п. 8. Первым в старте
   пачки 3 — P4 (`/story/`).
