# Секреты выкладки ac4bf-thewatch.com — что и куда положить

Инструкция для владельца. Займёт минут десять: один экран в панели хостера,
затем один экран на GitHub, где четыре раза повторяется одно действие.
Пароль робота в переписку не идёт — его вводите только вы, только на GitHub.

**Что происходит.** Робот (GitHub Actions) собирает сайт и заливает готовые
файлы на хостинг по FTPS — это FTP с шифрованием TLS, порт 21. Заливает
он от имени отдельного пользователя FTP `ax572417_claude`, которого вы
завели в панели; этот пользователь должен видеть **только папку сайта**.
Чтобы робот знал, куда и с каким паролем идти, ему нужны четыре значения,
и они хранятся в «секретах» репозитория на GitHub: там их видит только
робот, наружу они не показываются — даже вам после сохранения.

**Строка доступа из панели хостера** —
`ftp://ax572417_claude@ax572417.ftp.tools:21` — читается так:

| Кусок строки | Что это |
|---|---|
| `ax572417_claude` (до `@`) | логин пользователя FTP — пойдёт в `AC4BF_FTP_USER` |
| `ax572417.ftp.tools` (после `@`, до `:`) | хост — пойдёт в `AC4BF_FTP_HOST` |
| `21` (после `:`) | порт — пойдёт в `AC4BF_FTP_PORT` |
| пароля в строке нет | его вы задали при смене — пойдёт в `AC4BF_FTP_PASSWORD` |

## Шаг 1 — панель хостера: робот видит только папку сайта

*Экран: панель Хостинг Україна → раздел **Хостинг** → **Файли** → **FTP**
(на вики хостера раздел называется «Користувачі FTP»).*

1. В списке пользователей FTP найдите строку **`ax572417_claude`**.
2. Посмотрите колонку **«Каталог доступу»**. Там должно стоять
   **`ac4bf-thewatch.com/www`** — корневой каталог сайта. У этого хостера
   корень сайта — папка `www` **внутри** папки домена (по умолчанию
   `~/ac4bf-thewatch.com/www`); просто `ac4bf-thewatch.com` — это на уровень
   выше, туда заливать нельзя.
3. Колонка **«Тільки читання»** — должна быть **выключена** (робот пишет).

**Если в «Каталог доступу» пусто, стоит `/` или что-то другое** — робот
видит весь аккаунт, включая `7dtd.com.pl`. Заливать в таком виде нельзя:
робот приводит свою папку к точной копии сборки и **удаляет там всё
лишнее** — при доступе ко всему аккаунту лишним оказался бы соседний сайт.
Поправить: в строке пользователя → **«Зміна налаштувань»** (карандаш) →
раскрыть **«Додатково»** → **«Каталог доступу»** → ввести
`ac4bf-thewatch.com/www` (поле подсказывает существующие папки) →
сохранить. Если такой папки ещё нет — сначала создайте её в файловом
менеджере панели: папку `ac4bf-thewatch.com`, а внутри неё папку `www`;
потом вернитесь к пользователю.

**Как убедиться наверняка** (по желанию): подключитесь этим логином
из FileZilla (хост `ax572417.ftp.tools`, порт 21, шифрование «явный FTP
через TLS»): в правом окне вы должны увидеть либо пустую папку, либо
файлы сайта — но **не** папки с именами других сайтов и **не** папку `www`.

Робот это тоже проверит сам и откажется заливать, если увидит чужие
папки, — но лучше, чтобы до отказа не дошло.

## Шаг 2 — GitHub: страница секретов

*Экран: браузер, вы вошли в GitHub под своей учётной записью (владелец
репозитория).*

Откройте адрес — точно такой:

**https://github.com/Sniti01/site-generator/settings/secrets/actions**

Что должно быть на экране: заголовок **Actions secrets and variables**,
две вкладки — **Secrets** и **Variables**, — и зелёная кнопка
**New repository secret**. Вкладка **Secrets** должна быть активна
(она первая). Если вместо этого страница 404 — вы не вошли в GitHub
или вошли не под владельцем.

## Шаг 3 — четыре секрета, по одному на экран

Каждый секрет заводится одинаково:

1. Нажмите **New repository secret**.
2. В поле **Name** введите имя из таблицы — **буква в букву, заглавными,
   с подчёркиваниями**, без пробелов до и после.
3. В поле **Secret** вставьте значение из таблицы — тоже без пробелов
   до и после, без кавычек.
4. Нажмите **Add secret**. Вы вернётесь к списку — в нём появится имя.

Повторите четыре раза:

| № | Name — буква в букву | Secret — что вставить | Откуда это |
|---|---|---|---|
| 1 | `AC4BF_FTP_HOST` | `ax572417.ftp.tools` | строка доступа в панели, между `@` и `:`; то же — колонка «Хост» в списке пользователей FTP |
| 2 | `AC4BF_FTP_PORT` | `21` | строка доступа, после `:` |
| 3 | `AC4BF_FTP_USER` | `ax572417_claude` | строка доступа, до `@`; то же — колонка «Логін» |
| 4 | `AC4BF_FTP_PASSWORD` | новый пароль пользователя `ax572417_claude` | тот, что вы задали при смене пароля в панели; больше никуда его не вставляйте |

**Проверка после четвёртого:** в списке на этой странице ровно четыре
строки с этими именами. Значений GitHub не показывает никогда — это
нормально; если сомневаетесь в значении, нажмите на имя → **Update** и
введите заново, старое перезапишется.

**Чего не делать:** не заводить эти четыре значения во вкладке
**Variables** (переменные видны в журналах — это не место для пароля);
не создавать сейчас переменные `AC4BF_DEPLOY` и `AC4BF_LIVE` — они
включают выкладку по каждому коммиту и проверку живого домена, а домен
ещё не привязан (порядок запуска П52: ящик → домен → https → Search
Console). Робот и без них работает по ручной кнопке.

## Шаг 4 — скажите «секреты положены»

Дальше — первая выкладка ручным запуском при выключенном домене. Кнопка
запуска — у вас (доступа к ней у меня нет): **Actions** в шапке
репозитория → слева **Deploy ac4bf-thewatch.com** → справа кнопка
**Run workflow** → в открывшемся окошке оставить ветку **`main`**
как есть → зелёная **Run workflow**. Через минуту в списке появится
запуск; зелёная галочка — всё прошло, красный крест — робот остановился
и написал почему (журнал открывается щелчком по запуску; репозиторий
публичный, я его тоже читаю).

Робот соберёт сайт, проверит свою папку, зальёт 277 файлов и сам
пересчитает их на сервере; домен по-прежнему ничего не покажет — сайт
в панели не заведён, и это так и задумано. Потом с моей стороны —
`check-live` и доклад.

**Кнопка появится только после вливания `phase-4` в `main`.** Правило
GitHub: ручной запуск возможен, лишь когда файл workflow есть в основной
ветке (`main`); сейчас он есть только в `phase-4`. Вливание — ваше право
и ваш шаг: вместе со словами «секреты положены» скажите «вливай» — и я
влью `phase-4` в `main` перемоткой, как в П51, — либо влейте сами. Без
этого первая выкладка не стартует.
