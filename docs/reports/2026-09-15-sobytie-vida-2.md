# Открытые вопросы

## Технические — решены

- Порядок «правки → нулевой прогон → пересъёмка» исполнен так: контроль
  драйвера — на сборке без правок (два прогона, 0 различий), нулевой
  прогон против старого эталона — на сборке с правками (карта по месту),
  пересъёмка — три прогона; всё на одной сборке `dc5fc16`.
- Эталон главной — p2 (два прогона из трёх), не p1: правило большинства
  при бимодальном зерне.
- Рамки зон галереи игры переставлены по коробке `<img>` с оговоркой
  об отсутствии наблюдения на этой пересъёмке; удалять зону не стал —
  измерение того же элемента есть.
- `mapowanie.mjs` сессии вида взят без правок; вложенные места названы
  намеренными.
- Комментарии `site.ts` (шапка, лента, меню) приведены по факту вместе
  с правками, которые их касались; строки бэклога 5/38 — в фактах.
