# 7. Факты и находки вне объёма

**Находки вне объёма** — строками, не правками; записаны в бэклог 60
(`docs/BACKLOG.md`, 12 пунктов): альфа и длина hex в гейте контраста ядра (п. 1);
`theme-color` со `--bg` не сверяется (п. 2); судьи знака вне сборки (п. 3); иконки
проверены только Chromium (п. 4); у первого сайта только `favicon.svg` (п. 5);
у шапки ядра нет запасного фона без `color-mix()` (п. 6); пересчёт контуров букв
живёт в папке доклада (п. 7); знак дважды инлайном — +4260 B gzip (п. 8);
Playwright из временного кеша npx (п. 9); фавикон в выдаче поиска и имя сайта
в `<head>` (п. 10); кеш иконок при публикации (п. 11); имя зоны 9 эталона (п. 12).

**Факты, важные будущим сессиям:**

- **`visibility: hidden` не гасит SVG-фильтр `feTurbulence`** (зерно ядра `Grain`):
  шум остаётся в снимке. Скрывать зерно — `display: none` или `filter: none`.
- **Фаза растра при дробной плотности зависит от цепочки смещений.** Один и тот
  же SVG в фиксированном блоке в той же точке окна и в липкой шапке растрируется
  по-разному (до 7918 субпикселей при 1,25–1,75). Эталонный рисунок ставить
  с тем же началом отсчёта: у липкого предка — от него, иначе — от начала
  документа с той же прокруткой.
- **Chromium 151 в `<img>` берёт из ICO запись 32** (`naturalWidth` 32)
  и уменьшает; пиксельная запись 16 не видна. Вкладка при масштабе 1 и 1,75
  пересэмплирует иконку с тёмными ореолами.
- **Два режима плотности Chromium рисуют по-разному** (раунд 5, R5-MATERIALY-1,
  -4, -10). Настоящая плотность — окно, экран при 125–175 %, флаг
  `--force-device-scale-factor`: начало знака на пикселе устройства, при 1,25–1,75
  перекладина в полутоне при любой прокрутке, прокрутка квантуется по пикселям
  устройства. Эмуляция Playwright (`deviceScaleFactor`): знак на целом CSS px,
  край чёткий, когда координата × DPR целая, и фаза липкой шапки едет с прокруткой.
  Поэтому снимки «без окна» показывают чёткость, которой при 125–175 % нет
  ни на одном настоящем экране (`zamery/faza-perekladiny.json`,
  `okno-plotnosti.png`, DESIGN.md «Чёткость перекладины»).
- **Полоса прокрутки сдвигает знак на 1440 с x 132 на 127** (у Chromium без окна —
  10 CSS px; окно при 175 % рисует её в 16 пикселей устройства) — кадры эталона
  и снимки без окна по умолчанию её не видят; окна с полосой у судьи есть.
- **Tailwind 4 сбрасывает пространство темы по префиксу**: `--x-*: initial`
  убирает все ключи, которые начинаются с `--x-`, в любом `@theme`, в том числе
  `reference` и `default` (R5-SVERKA-1).
- **`page.on('request')` Playwright не видит WebSocket** — только
  `page.on('websocket')` (R5-MATERIALY-8).
- **Tailwind читает комментарии**: после каждой правки комментария в `src/` или
  `core/` — пересборка и сверка CSS побайтно.
- **Вес:** две копии `svg.znak` в `index.html` — 5191 и 5227 B; главная в gzip
  12 200 B против 7940 без знака (+4260 B, +54 %).
- **Снимок окна браузера** — `okno.ps1` по процессу со своим профилем
  (`--user-data-dir` с меткой), не по заголовку: так не снимается чужой Chrome.

# 8. Открытые вопросы

## Технические — решены

1. **Знак — SVG путями, не текстом**: буквы — контуры гарнитуры темы; сверка
   пересчитывает контуры из файла гарнитуры и сверяет побайтно.
2. **Три рисунка из одного источника** — шапка, иконка 32, пиксельная 16; иконки
   пишет инструмент красками из токенов, литералы равны токенам по построению.
3. **Судья «знак = эскиз A»** — против закреплённого sha256 эскиза, нарисованного
   на пустой странице литералами иконки эскиза, а не токенами сайта: смена токена —
   намеренный отказ.
4. **Материалы — только при нуле отказов**: всё снимается во временную папку
   и переносится в папку доклада целиком.
5. **После раунда 5 судьи не правились**, проза документов сужена по его находкам
   (`f6fcfaa`): sha256 инструментов во всех выгрузках равен файлам. Решение
   об остановке раундов — не моё, оно вынесено в «Политические» п. 2.
