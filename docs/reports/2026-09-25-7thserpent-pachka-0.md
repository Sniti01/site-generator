# 2. Маршрут `[...slug]` и строгая схема (п. 1)

По формам первого сайта, заново в LF (вынос в ядро — позже). Адрес — из поля `url`
файла содержания через `getPage` (адрес мимо структуры — прерванная сборка);
`title`, `description`, `h1` — из структуры; набор и порядок секций — `blocks[]`.
Сверки в порядке от частного отказа к общему: два файла на адрес и файл с адресом
«/»; текст под фронтматтером; вхождение блока дважды; поле схемы без места в карте
`POLE_BLOKA`; поле без блока; вхождение с ролью у блока вне `ROLE_UMIE`
(= `story-row`); ряд без своего вхождения; блок ядра без ветви маршрута; громкий
пропуск нереализованного в ядре (`video`: строка «блоки объявлены, но в ядре
не реализованы, пропуск» в журнале сборки); последним рубежом — «`blocks[]` =
напечатанному». Схема — `.strict()` у каждого объекта, строки текста — `trim().min(1)`,
id записи — путь файла.

**Решение исполнителя — ветви маршрута только со стендом или пробой.** Маршрут
пачки 0 печатает две ветви — `story-row` (с вхождениями по роли) и `link-list`.
Остальные блоки дерева, которые ядро умеет (`hero-key-art`, `byline`, `gallery`,
`cta-band`), приходят ветвью вместе с первой страницей своей формы — со стопом на ваши
глаза (план P4). Страница, объявившая такой блок, не собирается, и отказ говорит
именно «ветви нет». Причина: стенд `/404/` (ваш выбор) эти ветви не показывает;
у героя и призыва есть открытые вопросы вида (скрим ядра — литерал первого сайта,
бэклог 56 п. 2; композиция и контраст по арту); ветвь без стенда — непроверенный вид
в шаблоне. Цена — ветви героя, подписи, галереи и призыва пишутся в пачках текстов
(план P4 это учитывает). Если хотели полный маршрут сейчас — «Политические» п. 7.

**`h1`** — роль `.t-headline`, как `h1` главной (восемь ролей ядра, новых нет),
в `<header class="page-head container section">` — форма первого сайта: `.page-head` —
крючок без правил, вид решаете вы на стенде.
