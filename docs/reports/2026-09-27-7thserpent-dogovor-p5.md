## 8. Факты, важные будущим сессиям

1. **Astro экранирует** в тексте `& < > ' "`, в атрибутах — только `&` и `"`. Сырые `<` и `>` из `pages-s2.json` и записей
   кадров доходят до `description` и `alt`. Копия сторожа ищет `<meta>` выражением `<meta\b[^>]*>`, и один `>`
   в описании снимает его с суда. Новый разбор закрывает это для гайда (бэклог 68 п. 1).
2. **Судьи разбирают HTML регулярными выражениями.** Пять раундов над одним судьёй шли в основном по краям этого разбора
   и нормализации текста. При выносе судей нужен токенизатор HTML и одно извлечение текста для всех (бэклог 68 п. 2–3).
3. **Съёмка кадра элемента длиннее окна** склеивает липкую шапку поверх текста. Нужен полностраничный кадр с вырезом
   по рамке — `kadry-glavy.js`.
4. **`git add --renormalize --dry-run .`** печатает «add» для каждого отслеживаемого файла. Перенормализацию мерить
   счётом индекса после настоящего `--renormalize` на чистом дереве — `okonchaniya.mjs`.
5. **Сборка детерминирована.** Пересборка того же содержания даёт побайтно тот же `dist/` (176 файлов). Замеры
   прежней сборки можно переносить, но только со сверкой `sborki-ravny.mjs`.
6. **Агенты сверки без оболочки.** Корпус выгружен видимым текстом в скретчпад (612 файлов) для Grep и Read. Атаки агенты
   сдают заменами, прогоняет их ведущий на стенде. Команд оболочки у 26 агентов — 0.
