# Факты, важные будущим сессиям

1. **`:global` в `<style>` компонента доходит только до страниц, где
   компонент напечатан** — правила, общие нескольким страницам, живут
   в `global.css` (5б, 33). Тот же класс у `.rail-sec__item--*`
   (GuideRail) и `.hero__art { --era: var(--accent-2) }` (Hero) — пункт 41.
2. **Палитра ряда — от эпохи, без умолчания**; ключи вне `stronaEpoki`
   красятся `--accent`. Пачка 2: 13 игр по слагу — accent, пока нет карты
   игра → эпоха (пункт 37).
3. **Засечки шкалы — от стога**: любая правка выше стога двигает их;
   таблица по месту обязана нести строку «шкала».
4. **Playwright MCP сопоставим с CDP побайтово**; порядок по факту —
   `ПРОКРУТКА` до `ГОТОВНОСТЬ` под сроком (пункт 19 не чинился).
5. **Полные кадры при смене высоты — зона 4** (±1–2, светлые пиксели);
   оконные кадры — нет.
6. **Чанк главной ниже 4 КБ встраивается в HTML** — «HTML байт в байт»
   проверяется после приведения скрутов И с учётом встраивания.
7. **Отсоединённый checkout для нулевого прогона** восстанавливает
   `_baseline/` при возврате на ветку — mtime меняется, содержимое нет.
