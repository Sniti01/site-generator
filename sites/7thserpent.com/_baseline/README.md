§6, исполняемая часть — `docs/11_PRIEMKA.md` и `core/accept/frames.mjs`.

## Состав

Корень `_baseline/` — главная; следующая страница с эталоном получит
подпапку по слагу с теми же именами файлов (раскладка первого сайта).
Сверка одна: `npm run accept:frames -- check <кадры> _baseline`.

**Три рода кадров** (как у первого сайта): полный кадр — сторож, оконный —
судья (П12). Оконные — первый экран (`scrollY = 0`), **ряд** — центрируется
в окне по якорю секции (`К_ЯКОРЮ`, П39), **блок** — заголовок на 100 px
от верха окна (`К_ВЕРХУ`, П41 ответ 5).

## Зоны шума

Заведены сессией 9 **по замеру** (П79 п. 6: «зоны шума — только по замеру»),
только у полного кадра 390 (сторож) и только в местах, где дрожь измерена.

**Замер.** Пять прогонов одной сборки `2b838b7` одним драйвером
(`.playwright-mcp/sesja-2026-09-24-9/p1`–`p5`, вне git): p2, p4, p5
побайтово равны p1 на всех 13 кадрах; p3 против p1 — 12 кадров побайтово,
разошёлся один `baseline-mobile-full-390.png`: 49 736 субпикселей
при максимуме 3. Разложение по месту (рамки элементов из DOM при
`scrollY = 0`):

|---|---|---|---|---|
| `.hero__art` (0, 69, 391×339) | 20 926 | 3 | ключевой арт в дуотоне ядра (`mix-blend-mode`) под снегом `overlay` | `1` |
| первое окно вне арта, x ≥ 14, строки 0–850 | 81 | 1 | скрим (`color-mix`), зерно (в `fullPage` только первое окно) | `2-первое-окно-390-полный` |
| линия трассы, x < 14, строки 400–4557 | 760 | 1 | градиент линии фонаря | `3-трасса-390-полный` |
| `.panele` ряда 2003 (17, 2337, 357×221) | 19 | 2 | панели в дуотоне стали | `4-панели-2-390-полный` |

Итого 49 736; вне этих мест — 0. Оконные кадры-судьи (первый экран 390,
все ряды и блоки 1440) и полный кадр 1440 во всех пяти прогонах — 0 различий.
Природа та же, что записана в `MIGRATION.md` §6 для полного кадра: «в панелях
со смешиванием слоёв растеризация зависит от геометрии слоёв».

**Имя первой зоны — «1»**, как у первой зоны первого сайта: самопроверка
ядра (`core/accept/selftest.mjs`) при наличии `szum.json` требует зону «1»
и затем ищет кадр первого сайта `…layer-wlochy…` (у второго сайта — пропуск).
Привязка самопроверки к первому сайту — находка вне объёма (бэклог 58).

**С зонами:** `frames.mjs check` прогонов p2–p5 против этого эталона —
0 различий у p2, p4, p5; у p3 — `baseline-mobile-full-390.png` в допуске
всеми пятью зонами, вне допуска — 0. Зона не отменяет контрольного прогона:
амплитуда сверх записанной — отказ и повтор съёмки, а не расширение зоны.

## Драйвер и порядок

Playwright MCP (headless Chromium, HeadlessChrome 153), вьюпорт 1440×900 →
390×844 без перезагрузки (П16), `dpr` 1, полоса прокрутки не отнимает
ширины (`clientWidth` 1440/390 — в геометрии). Скрипты страницы
`ПРОКРУТКА`, `ГЕОМЕТРИЯ`, `К_ЯКОРЮ`, `К_ВЕРХУ` — дословно из
`core/accept/frames.mjs`, `ГОТОВНОСТЬ` — с ожиданием картинок под сроком
3 с (обход пункта 19 бэклога); осадка 700 мс и 2 rAF; проверка `scrollY`
каждого оконного кадра. Вшиты в код драйвера генератором
`docs/reports/2026-09-23-7thserpent-glavnaya/instrumenty/kadry-gen.mjs`
(копия генератора сессии 8 с профилем главной на 13 кадров; перед съёмкой
сверяет сайт на порту по `canonical`). Прод-превью (`astro preview`,
порт 4331), не dev-сервер. Все 17 картинок загружены в каждом прогоне
(«ГОТОВНОСТЬ»: 17/17), `scrollY` всех кадров совпал с ожидаемым.

**Движение в кадрах.** «Пуля» трассы — анимация по временной шкале
прокрутки (`view-timeline`), её положение задаёт `scrollY` кадра, не время:
при равном `scrollY` кадры равны (пять прогонов). Зерно (`Grain`,
`position: fixed`) в `fullPage` лежит только на первом окне.
