Часть 2 — замер на петле (Node v26.4.0; на раннере — Node 24), код дочернего процесса 0:
  контроль: верная цепочка (корень проб — в NODE_EXTRA_CA_CERTS): код fetch — ответ 200; сторож — отвечает, sertifikat=false
    причина: ответ 200 — «Поздравляем, сайт создан!», конечный хост 127.0.0.1:54229 — не имя сайта
  сертификат на другое имя (DNS:example.test): код fetch — ERR_TLS_CERT_ALTNAME_INVALID; сторож — не понять, sertifikat=true
    причина: ошибка сертификата ERR_TLS_CERT_ALTNAME_INVALID — https по этому имени браузер откроет только с предупреждением
  самоподписанный: код fetch — DEPTH_ZERO_SELF_SIGNED_CERT; сторож — не понять, sertifikat=true
    причина: ошибка сертификата DEPTH_ZERO_SELF_SIGNED_CERT — https по этому имени браузер откроет только с предупреждением
  промежуточный без CA:TRUE: код fetch — INVALID_PURPOSE; сторож — не понять, sertifikat=false
    причина: ошибка сети INVALID_PURPOSE
  лист только для clientAuth (не serverAuth): код fetch — INVALID_PURPOSE; сторож — не понять, sertifikat=false
    причина: ошибка сети INVALID_PURPOSE
  корень pathlen:0, под ним промежуточный CA: код fetch — PATH_LENGTH_EXCEEDED; сторож — не понять, sertifikat=false

  просроченный (2020-01-01…02): код fetch — CERT_HAS_EXPIRED; сторож — не понять, sertifikat=true
    причина: ошибка сертификата CERT_HAS_EXPIRED — https по этому имени браузер откроет только с предупреждением
  на порту https — простой http (TLS на имени не настроен): код fetch — ERR_SSL_WRONG_VERSION_NUMBER; сторож — не понять, sertifikat=true

    причина: ошибка сети UND_ERR_SOCKET

Вывод: шаблон по началу имени кода не совпадает с классом ошибки. Замерено: INVALID_PURPOSE (промежуточный без CA:TRUE,
лист только для clientAuth) и PATH_LENGTH_EXCEEDED — «ошибка сети — повтори; проверь записи DNS»; простой http на порту 443
(ERR_SSL_WRONG_VERSION_NUMBER) — «ошибка сертификата — браузер откроет только с предупреждением» (браузер не откроет вовсе).
По перечню Node вне шаблона также INVALID_CA, ERROR_IN_CERT_NOT_*_FIELD, CRL_*, UNSPECIFIED; в шаблоне — все ERR_SSL_*
протокола. Требование сертификата клиента — UND_ERR_SOCKET, «ошибка сети» (контроль). Все исходы — стоп; неверны причина и совет.
