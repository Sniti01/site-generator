## Что правили раунды (коротко)

1. Слова строки — функциями сторожа со сверкой по строке; перенос и `<br>` — пробел; невидимые знаки; любой неблочный тег —
   в двух прочтениях; границы `<main>` по маске; `<title>`, описания, `alt`/`title=`/`aria-label=` — строго; номер главы —
   ближайший заголовок; ряд — id и видимая метка; названия — в обоих прочтениях; охраны — код 2.
2. `<meta>` — маской TEG; охрана головы; значения атрибутов без снятия тегов; маска атрибутов; C0 до разделителя;
   `Default_Ignorable`, NFC; скрипты и стили в двух прочтениях; пробел перед знаком препинания; номер — отрезок от
   предыдущей `”`; `value=`, `placeholder=`.
3. Атрибуты по порядку; маска всех атрибутов; код по маске атрибутов; C0 только в тексте; `\v` `\f` DEL снимаются;
   хангыль — пробел; невидимые именованные сущности; голова до `<body>`; `<main-…>`; ряд и метка по тегам;
   заголовок без букв и цифр вокруг.
4. Место номера — белым списком ASCII; адрес — по знакам URL (расхождение со сторожем — код 2).
5. Только порчи и шапка.
