оглавления, ключи арта, адреса, `year` ≤ 9, вердикт без балла, дословные
совпадения с корпусом окнами по 8 слов, оценка длины. 36 агентов,
все отработали. Правки линзы фактов (минимальные, «остальное дословно»)

1. **Линза фактов может вернуть YAML без `---`** — разделители проверять

   низкое по природе кластеров; мерить стоит по нормализованным названиям.

   (Syndicate/Revelations против проводника) — при пачках 3–4 давать ей
