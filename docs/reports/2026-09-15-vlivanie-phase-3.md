## 4. Нужно от вас — списком, с вариантами

1. **Хостинг: где сайт будет жить.** Варианты: **(а)** тот же хостер, что
   у `7dtd.com.pl` (по заглушке «not configured» DNS уже ведёт туда):
   завести сайт в панели, корень — содержимое `dist/`, выпустить SSL
   в панели; плюс `.htaccess` по образцу соседа (редиректы https и без
   `www`, `ErrorDocument 404`) — Code; **(б)** Cloudflare Pages: DNS уже
   на Cloudflare, репозиторий на GitHub — подключить репозиторий, корень
   сборки `sites/ac4bf-thewatch.com`, команда `npm run build`, выход
   `dist/`; SSL, редиректы и 404 — сами; `.htaccess` не нужен; **(в)** любой
   другой хостинг по SFTP. **Рекомендация — (а), если у хостера уже оплачен
   тариф и там же почта `jakub@`; иначе (б)** — ноль ручных шагов
   на каждую выкладку. Нужно от вас: выбор и доступ (панель или SFTP/SSH
   для (а); подключение репозитория в Cloudflare для (б)).
2. **Деплой: как `dist/` попадает на сервер.** Варианты: **(а)** вручную
   по SFTP после `npm run build` — Code даёт команду и чек-лист, вы
   выкладываете; **(б)** GitHub Actions → SFTP/rsync на хостинг по секретам
   (`HOST`, `USER`, ключ) — выкладка по коммиту в `main`; **(в)** Cloudflare
   Pages из репозитория — выкладка по коммиту в `main` сама. **Рекомендация:
   при (а) хостинга — (б) деплоя; при (б) хостинга — (в).** Нужно от вас:
   для (б) — секреты в GitHub; для (в) — ничего сверх пункта 1.
3. **SSL и редиректы.** Сейчас `https://` не обслуживается (302 на `http`).
   При (а) хостинга — сертификат в панели (Let's Encrypt), при (б) — есть.
   Canonical у сайта — `https://ac4bf-thewatch.com/` без `www`: редирект
   `http` → `https` и `www` → без `www` обязателен до подачи в индекс.
   Нужно от вас: выпуск сертификата (а) или ничего (б).
4. **Search Console.** Свойство «домен» `ac4bf-thewatch.com` в вашем
   Google-аккаунте, подтверждение записью DNS TXT в Cloudflare (файла
   в `public/` не нужно), затем подача `https://ac4bf-thewatch.com/sitemap-index.xml`.
   Нужно от вас: аккаунт, TXT-запись, подача; Code — `robots.txt`
   со строкой `Sitemap:` до подачи.
5. **Почта `jakub@ac4bf-thewatch.com`.** MX на домене — в Cloudflare DNS;
   «куда пересылается» (П43 п. 4) по-прежнему не названо. Нужно от вас:
   подтвердить, что MX стоит и письма доходят, — иначе контакт
   на `/prywatnosc/` мёртвый.
6. **Что Code сделает сам после ответов 1–3** (одна сессия, коммит на файл,
   гейты): `public/robots.txt` (всё разрешено, `Sitemap:`), `src/pages/404.astro`
   по правилам маршрута (страница вне структуры — не в sitemap; `after-build`
   считает `h1` по `pages` — проба нужна), `public/.htaccess` при (а)
   с `<IfModule>`-обёртками по образцу соседа; при (б) деплоя — workflow.
   Пиксель эталонов это не трогает; `check` после — обязателен.

Не спрашиваю: аналитика (П42 — нет), кнопки соцсетей, партнёрские блоки —
